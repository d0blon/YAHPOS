# 🏔️ PatagoniaPOS - Ecosistema de Comercio Inteligente

PatagoniaPOS es una plataforma **SaaS (Software as a Service)** diseñada para modernizar el comercio en la Patagonia chilena. Combina un Punto de Venta (POS) ultrarrápido con un E-commerce integrado y un motor de facturación electrónica propio.

## 🚀 Características Principales

- **Motor DTE Independiente:** Integración directa con el SII sin intermediarios. Boletas ilimitadas.
- **Multitenancy Pro:** Capacidad para gestionar cientos de tiendas independientes bajo una sola infraestructura.
- **Diseño Glassmorphism:** Interfaz premium, moderna y fluida.
- **Modo Offline:** Vende incluso cuando el internet falla (Sincronización automática).
- **Fidelización Integrada:** Sistema de Puntos Patagonia para retener clientes.

## 🛠️ Stack Tecnológico

- **Frontend:** Next.js 14+ (App Router)
- **Base de Datos:** Supabase (PostgreSQL)
- **Estilos:** Tailwind CSS / Vanilla CSS
- **Criptografía:** Node-Forge / XML-Crypto (Para firmas SII)
