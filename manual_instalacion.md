# 📖 Manual de Instalación: Nuevo Cliente PatagoniaPOS

Este manual detalla los 5 pasos para dejar a un cliente operando en menos de 10 minutos.

### 1. Registro del Usuario
- Ve a la sección de registro en la plataforma.
- Registra el correo del dueño del negocio.
- Asigna el **Tier** (Básico, Pro o Elite) según lo contratado.

### 2. Configuración de Identidad
- Sube el Logo del negocio (formato PNG transparente recomendado).
- Configura el nombre comercial y el RUT de la empresa.
- Elige el color principal que coincida con la marca del cliente.

### 3. Carga del Certificado Digital (SII)
- Solicita al cliente su archivo `.pfx` y la clave.
- Sube el archivo a través del panel de configuración de la tienda.
- El sistema verificará automáticamente la validez del certificado.

### 4. Carga de Folios (CAF)
- Descarga los folios desde la web del SII (Boleta Electrónica).
- Sube el archivo XML generado por el SII al panel de folios.
- El sistema te dirá cuántas boletas tiene disponibles el cliente.

### 5. Prueba de Venta
- Realiza una venta de $1.
- Verifica que el XML se genere y se firme correctamente.
- ¡Listo! El cliente ya puede vender.
